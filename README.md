# Drill #13: 아이템 모드

기존 로고 → 타이틀 → 플레이 흐름에 아이템 선택 화면을 추가하는 과제입니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python main.py
```

이미지는 소스 파일 위치를 기준으로 불러옵니다.

## 구현 목표

- 플레이에서 I를 눌러 아이템 모드를 열고, 다시 I로 플레이에 복귀합니다.
- 0: 아이템 없음, 1: 작은 공, 2: 큰 공을 선택합니다.
- 아이템 화면에서 게임 진행을 멈추고, 선택한 공을 플레이에 적용합니다.
- 기존 P 일시정지, ESC 타이틀 복귀 기능을 유지합니다.

기능별로 커밋하여 모드 전환, 선택 UI, 공 적용, 검증 과정을 기록합니다.
