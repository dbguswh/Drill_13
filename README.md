# Drill #13: 아이템 모드

기존 로고 → 타이틀 → 플레이 흐름에 아이템 선택 화면을 추가하는 과제입니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python main.py
```

이미지는 소스 파일 위치를 기준으로 불러옵니다.

## 조작

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 로고 | 자동 | 2초 뒤 타이틀로 이동 |
| 타이틀 | Space | 새 플레이 시작 |
| 타이틀 | ESC | 실행 종료 |
| 플레이 | ← / → | 캐릭터 이동 |
| 플레이 | Space | 선택한 공 발사, 잠든 상태에서는 먼저 일어나기 |
| 플레이 | I | 아이템 모드 열기 |
| 플레이 | P | 일시정지 |
| 아이템 | 0 / 1 / 2 | 없음 / 작은 공 / 큰 공 선택 |
| 아이템 | I | 선택을 유지하고 플레이 재개 |
| 일시정지 | P | 플레이 재개 |
| 플레이·아이템·일시정지 | ESC | 타이틀로 복귀 |
| 모든 화면 | 창 닫기 | 실행 종료 |

아이템 선택은 위쪽 숫자키와 숫자패드를 모두 지원합니다. 숫자패드는 Num Lock을 켭니다.

처음에는 아이템이 없습니다. I → 1 또는 2 → I → Space 순서로 공 발사를 확인할 수 있습니다.
0은 장착을 해제하며, 이미 발사한 공은 그대로 날아갑니다.
아이템을 선택하면 노란색 테두리와 선택 이름이 표시되고, 캐릭터 옆에도 해당 공이 보입니다.

## 모드 동작

- `push_mode(item_mode)`로 플레이 위에 아이템 화면을 올립니다.
- 아이템 화면은 기존 배경과 캐릭터를 그리되 게임 월드를 업데이트하지 않습니다.
- I를 누르면 `pop_mode()`로 아이템 화면만 제거합니다. 캐릭터 위치, 선택, 날아가던 공이 유지됩니다.
- 정지된 시간은 잠들기까지의 대기 시간에서 제외합니다.
- 정지 중 방향키를 놓은 입력도 복귀 시 반영합니다.
- 타이틀로 돌아가면 플레이 월드를 정리하며, 다음 플레이는 아이템 없음으로 시작합니다.

## 검증

```powershell
python -m unittest discover -s tests -v
```

실제 SDL 소프트웨어 렌더러와 제공된 이미지·폰트를 사용하며, 테스트 창은 표시하지 않습니다.
추가 테스트 패키지는 필요하지 않습니다. 모드 전환, 모든 숫자키, 공의 이미지 크기,
선택 유지, 정지와 재개, 입력 해제, 대기 시간, 반복 진입, ESC와 창 닫기,
전체 게임 루프를 검증합니다.

직접 확인할 때는 다음 순서로 진행합니다.

1. `main.py` 실행 → 로고 → 타이틀 → Space.
2. I를 눌러 사진과 같은 아이템 패널이 뜨고 게임이 멈추는지 확인합니다.
3. 1 → I → Space로 작은 공, I → 2 → I → Space로 큰 공을 발사합니다.
4. I → 0 → I → Space로 새 공이 발사되지 않는지 확인합니다.
5. 이동하면서 I 또는 P로 멈추고 방향키를 놓은 뒤 복귀하여 이동이 고착되지 않는지 확인합니다.
6. ESC로 타이틀에 돌아간 뒤 새로 시작하고, 창 닫기로 종료합니다.
